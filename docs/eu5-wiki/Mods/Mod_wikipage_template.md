**Mod wikipage template** is a page that exists for you to copy the source and tweak to your liking with content from your own mod. It is here to increase the likelihood of mod wikis, their maintenance and to make use of PDX wiki servers instead of various third-party ones.

### Instructions for use of this page template

* Use `[{{Mod}}](/Template%3AMod "Template:Mod")`; for example, this page uses:

```
{{Mod
|logo=UNIQUEPREFIXHERE_modwikitemplate_thumbnail.png
|type=General Overhaul
|author=You! Me! and Them!
|status=(2025.11.04) For EU V v1.0.0
|forum=
|steam= REPLACE_ME
}}
```

* The fancy boxes use `[{{mainbox}}](/Template%3AMainbox "Template:Mainbox")` inside `{{[box wrapper](/Template%3ABox_wrapper "Template:Box wrapper")|align-items=stretch|justify-content=center}}`; these aren't necessary, but they do help to organize 'subpages'
* If additional pages are necessary, they should follow the format: `Mod name/Page name`. **Note:** These are not actual wiki subpages, only 'pseudo' subpages. These pages should include `{{[mod header](/Template%3AMod_header "Template:Mod header")|Mod name}}` on the first line, to add the header bar linking the page back to the mod's main page easily.
  + Links to these pages can be formatted with a pipe, for example `[[Mod name/Page name|Page name]]` which displays as [Page name](/index.php?title=Mod_name/Page_name&action=edit&redlink=1 "Mod name/Page name (page does not exist)").
  + Please do not create excessive subpages, particularly without any content. Mod information can and *should* be kept on its main page unless and until there is enough to warrant further organization.
* Screenshots, icons, and other images can be uploaded to the wiki, and should be clearly marked with the mod's name or abbreviation at the beginning of the file name and additionally be categorized with the mod using `[[Category:Mod name]]` on the file's page as well as the category `[Mod images](/Category%3AMod_images "Category:Mod images")`.
  + Files also need to be marked with a copyright template, such as `[{{C-Paradox}}](/Template%3AC-Paradox "Template:C-Paradox")`, `[{{C-PD-self}}](/Template%3AC-PD-self "Template:C-PD-self")`, or others in [Category:Copyright templates](/Category%3ACopyright_templates "Category:Copyright templates"). See [this page's logo file](/File%3AUNIQUEPREFIXHERE_modwikitemplate_thumbnail.png "File:UNIQUEPREFIXHERE modwikitemplate thumbnail.png") for an example. Files without a copyright may be removed at any time without notice.
