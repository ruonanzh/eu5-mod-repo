# Chivalric order

This article has been verified for the current [version](/Europa_Universalis_5_Wiki%3AVersioning "Europa Universalis 5 Wiki:Versioning") (1.3) of the game.

A Chivalric Order is an exclusive brotherhood of noble warriors dedicated to a country's martial ideals. Eligible characters may be invited to join, receiving the order's character modifiers and bonuses. The country itself gains the order's country modifiers as long as it has an active order and a ruler who is a member.
