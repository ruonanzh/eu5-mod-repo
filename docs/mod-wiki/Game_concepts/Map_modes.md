The map mode decides what is shown on the world map. The default map mode when a game is started or loaded is **Terrain**.

## Government map modes

[![Map mode bg.png](/thumb.php?f=Map_mode_bg.png&width=36)](/File%3AMap_mode_bg.png)[![Map mode square.png](/thumb.php?f=Map_mode_square.png&width=36)](/Map_modes "Map modes")[![Terrain.png](/thumb.php?f=Terrain.png&width=36)](/Map_modes "Map modes") Terrain: Displays terrain. This is especially important when deciding where we want to engage in combat, as some topography and vegetation impact the result.

Stripes indicate location with a controller that is not the owner.

## Military map modes

[![Map mode bg.png](/thumb.php?f=Map_mode_bg.png&width=36)](/File%3AMap_mode_bg.png)[![Map mode square mid red.png](/thumb.php?f=Map_mode_square_mid_red.png&width=36)](/Map_modes "Map modes")[![Military tactics.png](/thumb.php?f=Military_tactics.png&width=36)](/Map_modes "Map modes") Tactical: Indicates which locations have more defensive bonus, depending on climate and topography.
[![Map mode bg.png](/thumb.php?f=Map_mode_bg.png&width=36)](/File%3AMap_mode_bg.png)[![Map mode square mid red.png](/thumb.php?f=Map_mode_square_mid_red.png&width=36)](/Map_modes "Map modes")[![Fort.png](/thumb.php?f=Fort.png&width=36)](/Map_modes "Map modes") Fortifications: This colors the locations, depending on the diplomatic status with fort owners. Green locations indicate friendly forts, red locations indicate war enemy forts, and yellow locations indicate neutral forts.
[![Map mode bg.png](/thumb.php?f=Map_mode_bg.png&width=36)](/File%3AMap_mode_bg.png)[![Map mode square mid red.png](/thumb.php?f=Map_mode_square_mid_red.png&width=36)](/Map_modes "Map modes")[![Supply.png](/thumb.php?f=Supply.png&width=36)](/Map_modes "Map modes") Supply: This colors the locations depending on their supply limit. If no army is selected, red indicates a low supply limit, yellow indicates medium supply limit and green indicates a high supply limit. When an army is selected, locations which cannot support the selected army are red, while those that can are green. A location that can just barely support the selected army is colored yellow.
Military Access: Colors locations the selected country has military access to.
