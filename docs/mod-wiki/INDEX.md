## Relationship to the other references
- **mod-wiki is prose, not authoritative data.** It explains *how* systems work and the mod API
  concepts; it is a curated snapshot of eu5.paradoxwikis.com and may lag a patch behind.
- **Exact keywords / values → `game-scripts/` + the dumps.** For "does X exist / what value / which
  scope", grep `game-scripts/` (vanilla mirror, generated by `sync_game_scripts`) and
  [`../script_docs/`](../script_docs/) + [`../data_types/`](../data_types/) (game dumps). Those are
  the source of truth for exact names and values.
- **Live wiki** (eu5.paradoxwikis.com) has the latest version; re-sync mod-wiki with
  `scripts/crawl_eu5_wiki.py` when it drifts.
