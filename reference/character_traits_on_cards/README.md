Show Character Traits on Cards

A Europa Universalis V interface mod. Its main purpose is to show character traits directly on each row in Society → People → Characters, so you can see them at a glance without opening every character. You can also filter the list for rulers with the childhood traits Gifted or Prodigy, or with Elite childhood education.

Built for game version 1.x.

欧陆风云 5 界面向 Mod。主要功能是在社会界面「人物」列表的每一行人物卡片上直接显示特质图标，不必逐个点开角色即可浏览。另附带筛选：可列出拥有童年特质「天赋异禀」「天生奇才」的人物，或当前童年教育为精英教育的人物。

适用于游戏 1.x。
